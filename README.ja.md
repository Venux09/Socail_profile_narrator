# ソーシャルプロフィールナレーター 🎤

ソーシャルメディアプロフィールを分析し、AIが生成した物語を作成するプロジェクト。

このプロジェクトの目標は、ユーザーのソーシャルプロフィール（Instagram、Twitter、GitHubなど）を解析し、その人物のユニークなストーリーを生成することです。

---

## 機能

- ソーシャルメディアプロフィール情報を収集
- AIを使用してプロフィール分析を生成
- パーソナライズされたナレーション/ストーリーを作成
- 複数のプロフィール形式をサポート
